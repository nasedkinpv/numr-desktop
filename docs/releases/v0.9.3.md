# numr desktop 0.9.3

- Real file saving: Save (`Ctrl+S` / `Cmd+S`) writes back to the opened `.numr` file, Save As (`Ctrl+Shift+S` / `Cmd+Shift+S`) picks a new one. The header shows the file name and an unsaved-changes mark, and the last document is reopened on the next start.
- Light theme. Settings gets a System / Light / Dark switch; System follows the OS.
- The exchange-rate cache is shared with the numr TUI and CLI (`~/.config/numr/rates.json`), so one refresh serves every numr frontend for an hour.
- The logo hover animation no longer stalls on WebKitGTK.
