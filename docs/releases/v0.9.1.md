# numr desktop 0.9.1

- First release of the Tauri 2 desktop shell, replacing the Electrobun shell that lived in numr-web.
- Native Wayland and HiDPI on Linux through WebKitGTK; frameless rounded window, tray menu, `.numr` file association, drag-and-drop to open.
- Keyboard shortcuts: Ctrl/Cmd+N new, Ctrl/Cmd+O open, Ctrl/Cmd+S save, Ctrl/Cmd+R refresh rates, Ctrl/Cmd+W hide, Alt+Z wrap lines.
- Settings panel in the footer: line numbers, line wrapping, and display precision.
- Ships the numr 0.9.1 web runtime from numr-web.
